Lugic character builder

Everything you type stays in your browser, pictures included: a skill picture is not part of the code and is never sent anywhere. The one thing the page fetches from elsewhere is the game icons, which are linked from the Limbus Company wiki (limbuscompany.wiki.gg) unless they were saved beside the page; like any picture on a web page, that tells the wiki the visitor's address, but not the page or anything entered on it. The code is the character written out as text; the bot reads it when you paste it into /character import. The bot checks the build again with its own rules, so what it says is final.
